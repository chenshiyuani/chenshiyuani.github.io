Notes

Keeping a free VM alive with GitHub Actions

Some free platforms sleep when idle. A tiny scheduled GitHub Actions workflow that pings the machine every few minutes keeps it warm. The trick is to keep the interval polite and the script simple, and to accept that a free lunch always comes with house rules.

A field guide to free domains

Free domains are a small zoo: EU.org (free forever, manual review, full nameserver delegation), DigitalPlat domains such as dpdns.org and qzz.io (free renewal windows before expiry), KataBump subdomains, and developer subdomains like is-a.dev. I keep notes on which ones allow NS delegation to Cloudflare and which only allow simple records.

Why I settled on one proxy client

After trying sing-box, Xray and mihomo based clients side by side, I kept a single sing-box client in eBPF root mode. One well-understood tool beats three half-configured ones. Notes on rule sets, DNS splitting and urltest behaviour live here.
